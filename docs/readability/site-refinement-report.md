# サイト全体の整理・修正

2026-10-12。対象は公開画面の監査で挙げた改善点。医学的な判断や検索順位の改善を検証済みとする報告ではありません。

## 実装

- 配穴メモの固定の五行・主治を廃止。選択した穴を保存し、無料利用時の保存名は現在の穴名から作成する。空の選択は保存しない。既存の個人記録を自動編集しない。
- 料金・会員案内・症例・配穴で新規申し込みの受付状態を統一。確認中・停止・通信失敗を区別し、未確認のまま申し込み可能としない。機能の利用権限・決済処理は変更しない。
- 会員案内を短縮し、ダイアログの名前・キーボード操作・フォーカス復帰・狭い画面のスクロールを整備。
- トップの重複した対象者案内とフローを削除。更新情報は日付と見出しに短縮。主操作と補助リンクの見た目を整理。
- 学習案内は第1講・再開・11コースの順序へ集約。臨床ホームは下書き・主訴・経穴・記録と簡潔なツール一覧へ整理。
- 94講義のタイトルを先に表示。時間と完了操作を重複させず、目次・学習要点を開閉式に整理。進捗・基礎への戻り先・クイズ・本文・出典は保持。
- 361経穴の共通テンプレートで、定型概要・位置説明・FAQの重複を統合。固有の注意・標準記載・出典を維持。伝統的な主治と研究結果を別の節に整理。FAQPageマークアップを削除。
- 記事一覧は検索から結果を直接選べる構成へ。記事の重複著者紹介と一般広告を削り、出典と著者・確認状況を残す。Prime Student広告は文献ページへ集約。
- 症例は一覧と絞り込みを先に、追加演習は開閉式へ。用語集32語は分野・読み順・検索・詳説の開閉に対応し、既存のアンカーと関連講義を保持。
- 検索用データを631件・10種別の公開メタデータ索引へ分離。講義全文、問題の正解・解説、未確認症例、個人記録を同梱しない。用語の完全一致は定義・講義・記事の順を優先。
- ヘッダー・下部メニュー・フッターを短縮し、重複リンクと一般利用者向けのllms.txtリンクを削除。llms.txtファイルと既存のクロール許可は維持。
- アプリ追加案内の自動表示をやめ、設定メニューから開く方式へ。
- 未使用のHaiketsuOptimizerを削除し、専門確認の履歴は残す。実際の公開ページはpractice/haiketsu。

## 確認範囲

学習内容、問題の正答、学習履歴のID、公開URL、出典、既存の個人記録は維持。サイトの専門確認待ち146件は過去の監査記録として継続し、今回の表示整理を専門家監修と扱わない。Search Consoleの実績に基づくページ削除・統合やSEO/GEOの効果測定は実施していない。
