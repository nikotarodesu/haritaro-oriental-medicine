# 学習開始・読書時間・概念比較・配穴評価の改善

2026年10月12日。「他にも改善点ある？」への回答で提案した4項目を実装した。

## 変更

1. トップと学習案内に「初めての方：第1講から始める」を表示。概論の第1講へ直接進み、`?course=oriental-medicine-introduction`でコースの順番を引き継ぐ。従来のコース選択・臨床案内・学習再開も維持。
2. 全11コースのカードと詳細ページに、コースで選んだ講義の`duration`を合計した「読む目安」を表示。章の全講義やクイズ・演習時間を含めない。講義本文をサーバーで扱い、ブラウザーにはコースごとの数値だけを追加する。
3. 病機論の第1講にあるAさんの架空例を、病機論のコースにも掲載。「症状・所見」「病因」「病機」「証」を同じ記録から比較し、本人の報告・仮説・不足情報を分ける。スマホでは縦に並び、横スクロールせず読める。「残業が原因で肝気犯胃だ」と断定できるかを考える開閉式の問いと、元の講義へのリンクを追加。学習案内から比較へ直接進める。
4. 実際の配穴ページに「構成表示の判定条件を見る」を追加。内部の点数区分、減点条件、本治比率、検証の範囲を明示。従来どおり点数は表示せず、学習上の分類を表示する。保存時の「少数精鋭」を実際の分類結果の説明へ変更。現在は参照されない旧`HaiketsuOptimizer`も、「黄金比（2〜4穴）」などの表示を実装上の事実へ改め、共通の判定説明を使う。

## 配穴スコアの確認範囲

既存の`analyzePrescription`は100点から穴数、役割分類の併存、同系統の重複、本治・標治の偏りによる点数を引き、15〜100点に収める。1〜4穴は穴数による減点なし、5穴は15点、6穴以上は（穴数−5）×15点。穴数2〜4の黄金比や、本治比率40〜60％を理想とする条件は実装されていない。

この改稿は実装上の事実を説明するもの。点数や重み、経穴分類の臨床的妥当性・適用条件を専門家が確認したわけではない。効果・安全性・適切な穴数を点数から判断できないことを公開画面に記した。集計処理、選択、保存の処理、刺鍼条件、医学データは変更していない。

[専門確認一覧](specialist-review.md)の146記録を維持。旧ラベルの原文を確認履歴として残し、該当コンポーネントが現在の公開ルートから参照されていないことを訂正した。医学的な監修の完了として処理していない。
