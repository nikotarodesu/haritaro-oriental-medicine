# 添付指示書との再照合

2026年10月14日。2026年10月11日作成の「はり太郎の読みやすさと学習導線を改善するCodex実装指示書」を、既存の実装・校閲記録と現在の本番画面に照合した。

## 今回の追加修正

講義と経穴ページのスマホの水平余白を20pxから共通の16pxへ変更した。320px画面では本文・クイズに使える幅が265pxから273pxへ8px増える（15pxのスクロールバーがある環境）。変更は640px未満のページコンテナだけで、囲みを外したクイズ・選択肢・出典表示のスタイル、PCの読み幅は変更していない。

同じ作業フォルダーで進行中の図解変更を保護するため、`b890196`から分離した作業フォルダーで修正とビルドを行った。他の未コミット変更は今回の反映に含めない。

## 検証

- 修正前の現在の本番講義を320・375・390・430・1280pxで実測。横はみ出し0、スマホ本文と選択肢16px、問題内水平余白0、ヘッダーの明朝体を確認。
- `npm run test:learning`、`test:reading`、`test:site`、`test:editorial`が成功。実クイズハンドラー17フロー、94講義564選択肢の採点、復習・進捗・本文へのフォーカス、図と引用の既存検証を含む。
- 分離した修正の `npm run build -- --webpack` が成功。型チェックと573ページ生成。最初の試行ではGoogle Fontsの応答URL形式によるエラーが発生し、再試行で成功した。
- 現在の実コンポーネント・教材データ・公開CSSを用い、2問正解・1問不正解の通常／文字200%の静的検証HTMLを作成した。個人の回答履歴には書き込んでいない。
- 文字200%の新しい検証HTMLは、ブラウザーのローカルファイル閲覧制限により描画を再確認できなかった。以前の5画面幅の拡大検証結果は `text-200-results.json` にあるが、今回の再検証済みとは扱わない。実ユーザーのログイン・決済・患者記録を用いた保存も実行していない。
- 反映後の画面寸法と代表画像は、作業の最終報告に記載する。
