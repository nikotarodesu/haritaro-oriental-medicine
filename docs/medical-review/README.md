# 医学記述・出典・専門家監修の確認台帳

この台帳は確認対象の抽出結果です。自動抽出、書誌情報の一致、本文の照合、専門家による確認を同一視しません。現在、専門家による全件監修は未完了です。

## 対象と進め方

`statements.csv` は記事、講義、経穴、解剖、クイズ、症例、シミュレーター、古典、治療例、論文などのデータから抽出した記述です。URL・識別子・見出しなどは除外しており、画面内の文章や図版には別途の確認が必要です。全文から抽出した断片を、その前後の文脈と併せて確認してください。

2026-10-03の再生成から、用語集と保存用の配穴プリセットも確認対象へ追加します。古典は `SOURCE_CLASSICAL_TEXTS` を対象にし、掲載保留中の元資料と、公開用の電子本文引用の記録を含めます。台帳の更新は自動抽出であり、各記述の原典照合や専門家による承認の完了ではありません。

安全性・断定・数値・伝統分類と現代医学の対応に印のある記述を優先します。次に本文中の出典と、原典のページ・表・段落を照合します。動物研究、観察研究、RCT、総説、古典を区別し、研究対象・比較・期間・不確実性・一般化の限界を確認します。出典が存在するだけでは本文の主張の支持になりません。

`inventory.json` が作業記録の原本です。記述を確認した人が実際の `reviewer`（氏名）、`qualification`（資格・所属）、`source_locator`（原典URLまたは書誌と該当ページ・表・段落）、`decision`（確認内容・修正指示）、`reviewed_at`（確認日）を記録します。`review_status` は `pending` / `source-checked` / `expert-approved` / `needs-correction` / `unsupported` を使用します。

専門家による承認を受けていないものに `expert-approved` を付けません。確認台帳の更新だけでは公開本文は修正されないため、修正指示は対象ファイルに反映して再確認します。

再生成時には承認記録の必須項目を検査します。必須項目がそろうことは資格や承認の真正性の自動検証ではありません。担当者本人の実際の確認記録に基づいて入力してください。2026-10-02にユーザーが監修担当を「はり太郎本人」と指定しましたが、今回の本文の承認は未実施です。`owner-review-checklist.md` に確認対象をまとめています。

今回の編集照合は `acupoint-safety-review.md`、`article-accuracy-review.md`、`clinical-safety-review.md`、`yinyang-safety-review.md`、`safety-and-curriculum-review.md` に出典と範囲を記録します。非公開の論文・症例・手技原資料も台帳に含めます。台帳の件数は公開本文だけの数でも、確認済み件数でもありません。生成図や画面内の文章も別途確認してください。

再生成は `node scripts/medical-review-inventory.cjs`。同じファイル・位置・本文の記述だけ確認記録を引き継ぎ、文章が変われば未確認になります。CSVはJSONから再生成されるため、CSVに記入した確認記録はJSONへ移してから再生成してください。過去の版・監修者の確認記録はGit履歴に保存します。
