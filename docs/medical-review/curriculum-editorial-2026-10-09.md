# カリキュラム編集点検 2026-10-09

## 対象と範囲

全11章・94講・282問を一覧化し、講義リンク、章番号、問題の選択肢・正答位置、解説から戻る見出しを全件点検した。自動点検に加え、文章・学習目標・図解・問題の食い違い、重複設問、症例の接続を編集レビューした。

29講の本文を改訂。クイズだけを変更した講義も含め、34ページを10月9日改訂として記録する。講義URL・問題ID・章順は変更しない。これは医学的な正確性の全面保証、古典の逐語校訂、専門家監修、実技能力の評価ではない。

## 主な修正

| 問題 | 改訂 |
| --- | --- |
| 患者の申告した痛み・服薬回数を客観所見としていた | 本人の報告、観察・測定、解釈、未確認事項を区分 |
| 症例第5講で比較を教えるのに所見の羅列で終わっていた | 肝気鬱結・脾気虚・血虚・痰湿の比較表、暫定要約、見直す条件を追加 |
| 目標が改善・減薬を保証するように読めた | 本人の活動、評価指標、評価時期、薬の相談を分けた |
| SOAP記録を教えるのに実例がなかった | 頭痛の共通症例のS/O/A/P記録抜粋を追加 |
| 方法未確定の次講で特定配穴の成功談が突然登場した | 確認と同意後の架空分岐を明示し、固定処方や体験談風の成功描写を削除 |
| 直後・翌週・長期の評価が異なる内容へ飛んでいた | NRS、作業時間・中断、負担を引き継ぎ、不変・悪化の別分岐も追加 |
| 伝統分類と現代生理学が同一・実証済みと断定されていた | 気滞から腫瘍への一本道、脈と自律神経、補瀉と刺激量、利水の選択的排水などの断定を撤回 |
| 同じ主旨の問題や「次に学ぶ章」を問う問題が重複していた | 用語の役割、報告と所見、候補の支持・不足、症例の評価を問う問題へ変更 |
| 用語集の参照先で説明が欠け、症例の補助案内が別の主訴へ誘導していた | 5用語の文脈を補い、症例章の補助案内を頭痛と全段階の判断へ接続 |

既存の図解72箇所は保持し、本文の説明を図解の限定的な説明と整合させた。改訂した問題は既存のrevision判定で以前の正答履歴と区別される。

## 確認した公開資料

- [厚生労働省：こんな時は迷わず119へ](https://kakarikata.mhlw.go.jp/kakaritsuke/urgency.html)：突然の激しい頭痛・神経症状等の緊急案内。
- [NCCIH：Acupuncture: Effectiveness and Safety](https://www.nccih.nih.gov/health/acupuncture-effectiveness-and-safety)：作用機序の不確実性、有害事象、必要な受診を遅らせない原則。
- [Maryland Board of Acupuncture：SOAP](https://health.maryland.gov/bacc/Pages/Professional-Documentation-(SOAP-Notes).aspx)：本人の報告と観察・評価・計画の区分。日本の法的要件として転用しない。
- [NICE NG197](https://www.nice.org.uk/guidance/ng197/chapter/Recommendations)：1.2.7〜1.2.17の意思決定、選択肢、理解と再評価。直接取得は403だったため、公式ページの検索取得文で範囲を確認。新しい全面照合済み表示には変更しない。

## 再実行

```sh
node scripts/curriculum-editorial-audit.cjs --mode=summary --check
node scripts/curriculum-editorial-audit.cjs --mode=flags --series=practice
npm run test:editorial
npm run test:learning
npm run test:reading
npm run test:medical-safety
npm run test:site
npm run test:seo
```

`flags` の抽出語はレビュー候補であって誤り判定ではない。否定文や注意喚起も一致するため、件数を品質スコアとして扱わない。

## 残る確認

古典の版・原文・訳文、個々の伝統分類の定義と診断精度、特定の治法の研究は未完了の出典確認が残る。既存の「講義全体の検証・専門家監修を意味しません」という表示を維持する。受講者の理解度・離脱率への効果は公開後の実測が必要で、編集差分や自動テストから向上を断定しない。
