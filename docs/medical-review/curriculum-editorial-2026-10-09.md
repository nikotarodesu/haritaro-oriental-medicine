# カリキュラム編集点検 2026-10-09

## 対象と範囲

全11章・94講・282問を一覧化し、講義リンク、章番号、問題の選択肢・正答位置、解説から戻る見出しを全件点検した。自動点検に加え、文章・学習目標・図解・問題の食い違い、重複設問、症例の接続を編集レビューした。

初回は29講の本文を改訂し、クイズだけを変更した講義も含め34ページを10月9日改訂として記録した。初回追補で本文2講・問題2問・基礎13講の案内を修正し、対象は50講と用語集へ拡大。二度目の追補の章末演習と治療戦略の修正を含め、同日の改訂対象は55講となった。講義URL・問題ID・章順は変更しない。これは医学的な正確性の全面保証、古典の逐語校訂、専門家監修、実技能力の評価ではない。

## 主な修正

| 問題 | 改訂 |
| --- | --- |
| 患者の申告した痛み・服薬回数を客観所見としていた | 本人の報告、観察・測定、解釈、未確認事項を区分 |
| 症例第5講で比較を教えるのに所見の羅列で終わっていた | 肝気鬱結・脾気虚・血虚・痰湿の比較表、暫定要約、見直す条件を追加 |
| 目標が改善・減薬を保証するように読めた | 本人の活動、評価指標、評価時期、薬の相談を分けた |

| 伝統分類と現代生理学が同一・実証済みと断定されていた | 気滞から腫瘍への一本道、脈と自律神経、補瀉と刺激量、利水の選択的排水などの断定を撤回 |

| 用語集の参照先で説明が欠け、症例の補助案内が別の主訴へ誘導していた | 5用語の文脈を補い、症例章の補助案内を頭痛と全段階の判断へ接続 |

既存の図解72箇所は保持し、本文の説明を図解の限定的な説明と整合させた。改訂した問題は既存のrevision判定で以前の正答履歴と区別される。

- [Maryland Board of Acupuncture：SOAP](https://health.maryland.gov/bacc/Pages/Professional-Documentation-(SOAP-Notes).aspx)：本人の報告と観察・評価・計画の区分。日本の法的要件として転用しない。
- [NICE NG197](https://www.nice.org.uk/guidance/ng197/chapter/Recommendations)：1.2.7〜1.2.17の意思決定、選択肢、理解と再評価。直接取得は403だったため、公式ページの検索取得文で範囲を確認。新しい全面照合済み表示には変更しない。
- [WHO：中医学の標準用語の掲載概要](https://www.who.int/publications/i/item/9789240042322)：10月9日の追補で用語の共通化という刊行目的を確認。リンク先PDFは403のため、個々の定義を新たに照合済みとは表示しない。

## 追加指摘への対応

1. 病機第1講の本文・目標・要点を改訂。現代医学と「全く同一」、体内が凍結する、血流が詰まるなどの断定を削除し、報告・解釈・未確認事項を分ける架空例と解答を追加。図解と3問の参照先は維持し、未照合の古典引用は掲載を保留。
2. 用語集の相生・相克・相乗・相侮・陰陽・五労・弁証論治を本文と整合。関係の方向・伝統分類・比喩と、実測した生理機序・医学的な原因を区別。
3. 概論4講・臓腑5講・経絡4講に、学習例の整理・記録を練習する案内を追加。実画面では基礎講の表示条件でも隠れていたため、表示側も修正。基礎13講は用語集へ接続し、後半の臨床演習への案内と区別した。全94講分の案内データの描画・公開ルート、基礎13講の専用表示、各章の実際の講義画面を回帰テストで検証。以前は通常の実行対象外だった臨床ワークフローテストと編集テストを`test:learning`へ組み込み。
4. 生命機能第12講と五行第8講の第3問を、章の順序ではなく、生成・巡り・排泄の分類、相乗・相侮の方向の区別を問う問題へ変更。五行第8講の本文にも具体例を追加。問題IDは維持し、問題改訂の判定は既存のrevision機構を使用。

## 二度目の追加指摘への対応

1. 治療戦略第9講のタイトル・学習目標を本文に合わせ、介入方法と刺激量の検討事項・保留条件までを学ぶ範囲とした。個別の施術条件を設計できるという到達保証をしない。
2. 第12講の44歳男性について、頭痛日数・痛み・作業中断・市販薬の申告を具体化。情志・食欲・便通・舌脈がない状態で肝気鬱結・脾気虚を絞り込まず、学生の未検証の仮説として根拠不足を示した。
3. 計画書を指示だけの表から、症例の申告値・未確認事項・保留理由・評価条件が入った7項目の記入例へ変更。記録期間は受診や安全確認を待つ期間ではないと明記し、施術の実施を前提にしない。
4. 治療戦略の44歳男性と、統合症例の43歳女性が別人であることを、前章の終わりと次章の入口の両方で明示。統合症例章内の縦断的な設定は維持。
5. 章末演習で各講クイズを再掲していた88問を新規に作成。分類・役割・関係の方向・情報の読み取り・候補比較を各章の範囲で問い、元から独立していた11問と合わせ99問とした。全11章の記述課題に、提示情報を使った解答例と章固有の3項目の振り返り基準を追加。

章末問題のデータを各講のクイズから分離し、各問から同じ章の本文見出しへ復習できる構成とした。章末問題はもともと正答履歴を保存しないため、問題IDを維持しても過去の正答が新問へ引き継がれることはない。保存済みの記述ノートは本人の過去の記録として変更しない。

この追補を含む同日の改訂対象は55講。未変更の講義を一律に改訂済みとは表示しない。新しい問題の根拠は対応する講義本文であり、未照合の古典や個々の研究を新たに確認済みとするものではない。
