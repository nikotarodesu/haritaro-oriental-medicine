# はり太郎の東洋医学 ポータルサイト

「はり太郎の東洋医学」の膨大な知見を体系化した、日本最高峰の東洋医学総合ポータルサイトです。
伝統的な東洋医学の智慧（経穴・経絡・気血水・陰陽五行）と、最新の神経生理学・学術論文を融合させています。

---

## 主な機能とページ構成

1. **トップページ (`/`)**
   - サイトビジョン、二十四節気・今月の養生アドバイス、両輪設計の案内、基本の要穴ピックアップ、知見記事ハイライト
2. **経穴・ツボ辞典 (`/tsubo`)**
   - 全361穴対応基盤。部位別（頭部、首・肩、背中・腰、手・腕、足・脚、胸・腹）および経絡別フィルター
   - 一般向けのやさしい取穴法と、専門家向けの骨度法・解剖学的取穴モーダル
   - はり太郎の臨床知見、主治、禁忌事項の明記
3. **お悩み・症状別ガイド (`/symptoms`)**
   - 頭痛・首肩こり、不眠・ストレス、胃もたれ、生理痛・冷え、慢性疲労など
   - 東洋医学的メカニズム、特効穴、食養生、生活改善ストレッチ
4. **気血水 体質セルフ診断 (`/diagnosis`)**
   - 12問の問診に回答することで、気虚・気滞・血虚・瘀血・水滞・陽虚の6タイプを判定
   - タイプ別の原因、現れやすいサイン、食材、ツボ、生活指導を自動提示
5. **知見・臨床録・論文抄読 (`/articles`)**
   - テキスト、ブログ記事、学術論文データをカテゴリ別（論文抄読、経絡学、セルフケア）に美しく表示
6. **サイトについて (`/about`)**
   - サイト理念、3つの編集基準、医療情報に関する免責事項

## 既存の知見・記事・ツボの追加方法

### 1. 記事や論文を追加・編集する場合
`src/data/articleData.ts` に記事オブジェクトを追加するだけで、自動的に一覧と詳細に反映されます。

```typescript
{
  id: "article-slug",
  title: "記事のタイトル",
  category: "論文・文献抄読" | "経穴・経絡学" | "一般向けセルフケア",
  publishedAt: "2026-03-10",
  readTime: "5分",
  summary: "記事の要約文...",
  tags: ["タグ1", "タグ2"],
  author: { name: "はり太郎", role: "東洋医学臨床家・研究者" },
  contentMarkdown: `## 見出し\n\n本文...`
}
```

### 2. ツボ（経穴）を追加・編集する場合
`src/data/tsuboData.ts` に追加します。

## 既存のGitHub & Vercelで公開する手順

### Step 1: GitHubに新しいリポジトリを作成
1. お使いのGitHub（スト6と同じアカウント）にログイン。
2. 右上の「＋」→「New repository」をクリック。
3. リポジトリ名（例: `haritaro-oriental-medicine`）を入力して「Create repository」。

### Step 2: このプロジェクトをGitHubへプッシュ
ターミナルで以下のコマンドを実行します：

```bash
git add .
git commit -m "feat: はり太郎の東洋医学ポータル初期リリース"
git branch -M main
git remote add origin https://github.com/<あなたのユーザー名>/haritaro-oriental-medicine.git
git push -u origin main
```

### Step 3: Vercelに新しいプロジェクトとして追加
1. お使いのVercel（スト6と同じアカウント）にログイン。
2. ダッシュボード右上の「Add New...」→「Project」をクリック。
3. GitHubリポジトリ一覧から `haritaro-oriental-medicine` を見つけて「Import」。
4. 設定は変更不要（Next.jsが自動認識されます）で「Deploy」をクリック。
5. 約1分で世界中に公開され、専用のURL（`xxx.vercel.app`）が発行されます。
